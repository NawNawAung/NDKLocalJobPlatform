# Website images

These files are served directly from `/images/...`. Replace the sample SVGs with your own artwork, keeping the same filenames, or update the matching `src` in the Vue component.

| Use | File | Shown on |
| --- | --- | --- |
| Website logo mark | `brand/site-logo.svg` | Shared header and footer |
| KBZ Group logo | `companies/kbz-group.svg` | Home page and employer dashboard |
| Grab Myanmar logo | `companies/grab-myanmar.svg` | Home page and recommended job card |
| Wave Money logo | `companies/wave-money.svg` | Home page and recommended job card |
| CDSG Group logo | `companies/cdsg-group.svg` | Home page |
| Job seeker profile cover | `profile-cover.svg` | Profile banner |
| Technology category icon | `categories/technology.svg` | Home page category card |
| Finance category icon | `categories/finance.svg` | Home page category card |
| Engineering category icon | `categories/engineering.svg` | Home page category card |
| Administration category icon | `categories/administration.svg` | Home page category card |

For PNG or JPG files, put them in this folder and change the corresponding path, for example `/images/companies/kbz-group.png`.
